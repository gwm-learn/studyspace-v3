## 3 · 待补清单

只列**该由本目录写**的条目。每条给：计划要点、建议落点、先读什么、写完能回答什么、优先级。

### M02 启动链与板级适配

- **计划要点**：上电 → U-Boot → 内核设备树 → rootfs → procd 的完整链路；U-Boot 环境变量/启动参数/分区定义/TTL 调试；DTS 里的网口、WiFi、SPI/NAND、GPIO、LED、复位键；分区布局与救砖（TFTP 刷机、分区损坏修复）。
- **现状**：[05-升级与恢复](./05-升级与恢复/.readme.md) 只覆盖了"升级侧"（sysupgrade、双分区、failsafe），**启动侧完全空白**。
- **建议落点**：新建 `07-启动与板级/`，四篇：`00-启动链总览`、`01-U-Boot与启动环境`、`02-DTS与板级配置`、`03-分区布局与救砖`。
- **先读**：[01-构建与包管理/04-镜像生成与Device-Profile](./01-构建与包管理/04-镜像生成与Device-Profile.md)、[05-升级与恢复/02-双分区与回滚](./05-升级与恢复/02-双分区与回滚.md)。
- **写完能回答**：设备起不来时，怎么在 30 秒内判断卡在哪个阶段？改 LED 触发为什么要动 DTS 而不是脚本？分区表改了以后，sysupgrade 为什么还要跟着改？
- **优先级**：高（计划里缺口最大的一环，商用项目的门槛）。

### M04 无线子系统与驱动

- **计划要点**：MT76 驱动架构、mac80211/hostapd/wpa_supplicant 联动、AP/Client/中继/桥接的底层差异。
- **现状**：[04-无线](./04-无线/.readme.md) 已覆盖用户态配置、射频参数、漫游与 EasyMesh；**驱动层与工作模式缺**。
- **建议落点**：驱动架构归 [30-平台与芯片](../../30-平台与芯片/.readme.md)（芯片相关）；`04-无线` 内补一篇"工作模式与转发差异"（AP/STA/中继/4 地址）——注意与 [04-漫游与EasyMesh §7 回程](./04-无线/04-漫游与EasyMesh.md) 去重，那边讲回程，这边只讲模式。
- **先读**：[04-无线/00-无线子系统总览](./04-无线/00-无线子系统总览.md)。
- **写完能回答**：中继和桥接在帧格式上差什么？为什么 STA 模式不能直接当 AP 用？
- **优先级**：中。

### M06 LuCI 框架

- **计划要点**：MVC 结构、页面渲染、uci 读写、前后端交互；从零写一个页面绑定配置。
- **现状**：完全没有。现有笔记只到"uci 配置文件"这一层，没有"页面怎么改配置"。
- **建议落点**：新建 `09-LuCI/`，两篇：`00-LuCI架构与MVC`、`01-写一个页面并绑定uci`。
- **先读**：[02-系统框架/03-UCI](./02-系统框架/03-UCI.md)、[06-定制与裁剪/01-品牌与默认配置](./06-定制与裁剪/01-品牌与默认配置.md)。
- **写完能回答**：页面保存后，配置是怎么从 `ubus` 走到 `uci` 再到服务的？为什么改完要 `uci commit`？
- **优先级**：中。

### M08 量产与稳定性

- **计划要点**：固件瘦身、开机速度、内存占用；72 小时长稳、压力拨号、无线压力连接；日志分级与异常上报；版本迭代、配置保留、OTA 适配。
- **现状**：[06-定制与裁剪](./06-定制与裁剪/.readme.md) 有"怎么裁"，没有"怎么验"。
- **建议落点**：新建 `10-量产与排障/`，两篇：`00-瘦身与启动优化`、`01-长稳与压测方法`。
- **先读**：[06-定制与裁剪/02-裁剪-补丁与SDK集成](./06-定制与裁剪/02-裁剪-补丁与SDK集成.md)、[05-升级与恢复/01-sysupgrade](./05-升级与恢复/01-sysupgrade.md)。
- **写完能回答**：怎么量化"这版固件变慢了"？长稳测试跑什么指标、什么算失败？
- **优先级**：低（依赖 M02/M06 的结论）。

### M09 网络服务：dnsmasq

- **计划要点**：dnsmasq 的 DHCP + DNS 双角色、租约与静态绑定、上游 DNS 与缓存、与防火墙/NAT 的配合。
- **现状**：[03-网络数据面](./03-网络数据面/.readme.md) 只讲 WAN 侧接入，**LAN 侧服务层空白**。
- **建议落点**：新建 `08-网络服务/`，两篇：`00-dnsmasq与DHCP`、`01-DNS解析链路与缓存`。
- **先读**：[03-网络数据面/04-WAN接入与PPPoE](./03-网络数据面/04-WAN接入与PPPoE.md)、[02-系统框架/04-netifd设备与接口模型](./02-系统框架/04-netifd设备与接口模型.md)。
- **写完能回答**：设备拿到 IP 的全过程里，dnsmasq 在哪一步、netifd 在哪一步？`/etc/config/dhcp` 改了为什么有时不生效？
- **优先级**：高（日常出现频率最高的服务层）。

### M13 分层排障

- **计划要点**：从应用 → netifd → 内核 → 驱动逐层定位；固件构建复盘。
- **现状**：各篇都有"异常分支"，但没有一篇讲**跨层怎么缩小范围**。
- **建议落点**：`10-量产与排障/02-分层排障.md`（与 M08 同目录）。
- **先读**：[02-系统框架/05-netifd接口生命周期](./02-系统框架/05-netifd接口生命周期.md)、[03-网络数据面/00-数据面总览](./03-网络数据面/00-数据面总览.md)。
- **写完能回答**：WiFi 能连上但上不了网，先看哪一层？怎么用一句话判断问题在 netifd、内核还是驱动？
- **优先级**：中。

## 名词解释

> 缩写给出英文全称；非缩写用“—”表示。本表只解释地图里出现的词，机制细节去对应笔记。

| 术语 | 英文全称 | 解释 |
| --- | --- | --- |
| DSA | Distributed Switch Architecture | Linux 的交换机驱动框架，端口对应独立 netdev。 |
| LuCI | Lua Configuration Interface | OpenWrt 的 Web 管理界面框架，MVC 结构。 |
| MT76 | — | 联发科 Wi-Fi 驱动的开源项目名。 |
| MTK | MediaTek | 联发科，Filogic 系列是主流路由 SoC。 |
| QCA | Qualcomm Atheros | 高通无线/网络芯片系列。 |
| procd | Process Daemon | OpenWrt 的 init 与进程管理服务。 |
| netifd | Network Interface Daemon | 网络接口与协议调度的守护进程。 |
| ubus | Micro Bus | OpenWrt 的进程间通信总线。 |
| UCI | Unified Configuration Interface | OpenWrt 的统一配置系统。 |
| DTS | Device Tree Source | 设备树源文件，描述板级硬件。 |
| U-Boot | Das U-Boot | 常用的嵌入式引导程序。 |
| dnsmasq | — | 轻量 DHCP + DNS 服务，OpenWrt 默认使用。 |
| failsafe | — | OpenWrt 的救援模式，在 preinit 阶段拦截启动。 |
| TR-069 | CPE WAN Management Protocol | 运营商远程管理 CPE 的协议。 |
| TR-369 | User Services Platform | TR-069 的后续标准（USP）。 |
| QMI | Qualcomm MSM Interface | 高通模组的控制接口，常用于 5G/LTE 拨号。 |
| MBIM | Mobile Broadband Interface Model | 蜂窝模组的标准化接口。 |
| netns | Network Namespace | Linux 网络命名空间，用于隔离网络栈。 |
| netlink | — | Linux 内核与用户态之间的套接字通信机制。 |
| GPIO | General Purpose Input/Output | 通用输入输出引脚。 |
| OTA | Over-the-Air | 远程升级。 |
