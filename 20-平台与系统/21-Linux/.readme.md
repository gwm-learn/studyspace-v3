# 目录说明

Linux 通用知识：内核、驱动、启动、进程、内存、网络与调试。产品定制和厂商 SDK 差异放到 22/40。

## 内容

- [01-内核基础](./01-内核基础/.readme.md)：内核概览、模块、中断、同步（4 篇）
- [02-驱动与设备树](./02-驱动与设备树/.readme.md)：驱动模型/DT、GPIO/LED、字符/块/网络/I2C/USB、分层（9 篇）
- [03-启动与根文件系统](./03-启动与根文件系统/.readme.md)：启动链、rootfs/init、启动失败定位（3 篇）
- [04-进程与并发](./04-进程与并发/.readme.md)：进程/线程、调度、IPC/信号、namespace/cgroup（4 篇）
- [05-内存与性能](./05-内存与性能/.readme.md)：虚拟内存、分配器/页缓存、OOM/性能（3 篇）
- [06-网络子系统](./06-网络子系统/.readme.md)：网络栈、收包/发包、socket/epoll、网桥/netlink、netfilter（6 篇）
- [07-调试与追踪](./07-调试与追踪/.readme.md)：调试概览、ftrace/perf、gdb/crash（3 篇）
