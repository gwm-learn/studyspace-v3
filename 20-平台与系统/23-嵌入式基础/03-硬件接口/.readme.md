# 目录说明

UART/I2C/SPI/GPIO/Flash/eMMC 等硬件接口与调试。

## 内容

- [00-UART与串口调试.md](./00-UART与串口调试.md)：8N1 帧、TTL/RS-232/RS-485 电平、调试链路与乱码排查。
- [01-I2C与SPI总线.md](./01-I2C与SPI总线.md)：两线/四线拓扑、CPOL/CPHA 模式、上拉与总线恢复。
- [02-GPIO与中断.md](./02-GPIO与中断.md)：pinmux、电气配置、中断路径与去抖取舍。
- [03-Flash与存储接口.md](./03-Flash与存储接口.md)：NOR/NAND/eMMC/UFS 对比、寿命估算与掉电保护。
