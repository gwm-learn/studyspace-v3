# 目录说明

交叉编译、Boot/升级、硬件接口、功耗与热设计等嵌入式通用能力。共 13 篇正文、13 张图。

## 内容

- [01-交叉编译与工具链](./01-交叉编译与工具链/.readme.md)：工具链组成、三元组、ABI/sysroot、Yocto 构建（3 篇）
- [02-Boot与升级](./02-Boot与升级/.readme.md)：Flash 布局与启动介质、U-Boot、A/B 升级与安全启动（3 篇）
- [03-硬件接口](./03-硬件接口/.readme.md)：UART、I2C/SPI、GPIO 与中断、Flash 与存储（4 篇）
- [04-功耗与热设计](./04-功耗与热设计/.readme.md)：功耗测量与预算、休眠唤醒、温控与散热（3 篇）

## 边界

- 本目录只写**跨平台通用的嵌入式能力**：构建、引导、接口、功耗与热。
- 通用 Linux 启动链、驱动模型归 [21-Linux](../21-Linux/.readme.md)。
- OpenWrt 的构建体系、sysupgrade、failsafe 归 [22-OpenWrt](../22-OpenWrt/.readme.md)。
- 具体 SoC 的 BootROM、烧录工具、时钟树归 [40-平台与芯片](../../40-平台与芯片/.readme.md)。
- 产品形态、能效指标与安规要求归 [30-产品与方案](../../30-产品与方案/.readme.md)。

## 维护约定

- 新增笔记后，在本文件补充链接和一句话摘要。
- 跨主题内容用链接引用，不在本目录重复维护。
- 配图放在各子目录 `images/`，命名 `图NN-主题.svg`，生成方式见 `.图表模板/figure-style.md`。
