# 图片索引

本目录存放 Docker 系列笔记的插图，由 `.图表模板/svg-figure-template.py` 生成。原有 6 张按篇顺序重排为 图01–图06；新增的 3 张接续编号为 图07–图09，分属三篇的"失败定位 / 启动时序"章节。

- [图01-镜像分层.svg](./图01-镜像分层.svg)：镜像只读层叠加、容器可写层，以及 tag/digest/layer/container 的可变性对比。
- [图02-构建缓存与多阶段.svg](./图02-构建缓存与多阶段.svg)：缓存链在哪一步失效，多阶段构建如何把工具链留在 builder。
- [图03-容器网络模式.svg](./图03-容器网络模式.svg)：bridge/macvlan/host 三种接入方式的数据路径与边界。
- [图04-容器存储与生命周期.svg](./图04-容器存储与生命周期.svg)：容器根文件系统与可写层、volume/bind mount/tmpfs 的持久性对比。
- [图05-Compose拓扑.svg](./图05-Compose拓扑.svg)：声明文件、Compose 项目、服务、网络与卷的关系。
- [图06-交叉编译环境.svg](./图06-交叉编译环境.svg)：宿主源码经 bind mount 进入工具链容器，产物写回宿主。
- [图07-构建失败定位.svg](./图07-构建失败定位.svg)：上下文 / 指令 / 产物三段的失败现象与对应动作。
- [图08-连不通定位.svg](./图08-连不通定位.svg)：出不去 / 进不来 / 名字不通三路的证据点与修法。
- [图09-Compose启动时序.svg](./图09-Compose启动时序.svg)：up 的四个阶段及各阶段的常见失败。
