# 目录说明

企业/家庭 WLAN 的 AP 与 AC 产品：AP 形态与射频、AC 与 CAPWAP、组网与漫游、覆盖与验收。产品层只写整机、组网和验收；802.11 原理链接到 10，hostapd/驱动链接到 20，芯片链接到 30。

共 4 篇，12 张 SVG。

## 内容

- [00-AP产品架构](./00-AP产品架构.md)：吸顶/面板/室外等形态、软硬件链、Fat/Fit/云模式、转发位置与上线状态机。
- [01-AC产品架构与CAPWAP](./01-AC产品架构与CAPWAP.md)：AC 形态、CAPWAP 报文/状态机/定时器（RFC 5415）、容量许可与双机切换边界。
- [02-AC-AP组网与漫游](./02-AC-AP组网与漫游.md)：二层/三层组网、集中/本地转发、漫游三种边界与认证加速机制。
- [03-WLAN覆盖与验收](./03-WLAN覆盖与验收.md)：AP 布点、信道/功率、容量推导链与验收判据。
