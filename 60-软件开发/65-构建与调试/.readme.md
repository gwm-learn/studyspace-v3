- [01-Make与CMake.md](./01-Make与CMake.md)：Make 依赖与自动依赖、CMake 目标模型与可见性、工具链文件。
- [02-调试与诊断.md](./02-调试与诊断.md)：GDB/core、ASan/UBSan、Valgrind、strace、perf 与问题分类。
