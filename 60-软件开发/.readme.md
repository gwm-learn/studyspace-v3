# 目录说明

C 语言、数据结构、Shell、构建与调试。面向嵌入式/网络软件开发的编程能力：语言规则、结构与算法选型、脚本自动化、工具链与诊断。

## 内容

- [61-C语言](./61-C语言/.readme.md)：对象与内存模型、指针、结构体、宏与链接、嵌入式工程实践（5 篇）。
- [62-数据结构与算法](./62-数据结构与算法/.readme.md)：复杂度与选型、线性结构、树与堆、图、查找与排序（5 篇）。
- [63-Shell](./63-Shell/.readme.md)：执行模型与语法、文本处理、脚本工程化与自动化案例（3 篇）。
- [65-构建与调试](./65-构建与调试/.readme.md)：编译链接、Make/CMake、调试与诊断（3 篇）。

合计 16 篇笔记、16 张 SVG 插图。

## 边界

- 本目录只讲**编程语言与通用工程方法**；具体平台构建（OpenWrt/Yocto）链接到 [20-平台与系统](../20-平台与系统/.readme.md)。
- 开发环境与效率工具（Git/Docker/WSL）链接到 [80-工具与环境](../80-工具与环境/.readme.md)。
- 协议与产品实现链接到 `10-基础理论`、`40-产品与方案`，不在本目录重复。
