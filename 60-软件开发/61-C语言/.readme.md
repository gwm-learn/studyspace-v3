# 目录说明

C 语言的对象模型、指针、结构体、宏与嵌入式工程实践。讲“语言规则怎么落到内存和编译产物”，不展开具体芯片 SDK。

## 内容

- [00-C语言对象与内存模型.md](./00-C语言对象与内存模型.md)：存储期、链接属性、进程内存布局、对齐与字节序。
- [01-指针数组与字符串.md](./01-指针数组与字符串.md)：指针步长、数组退化、函数指针、字符串边界。
- [02-结构体联合与位域.md](./02-结构体联合与位域.md)：填充规则、柔性数组、联合双关、线格式。
- [03-宏预处理与编译链接.md](./03-宏预处理与编译链接.md)：宏展开纪律、头文件组织、符号与链接属性。
- [04-嵌入式C工程实践.md](./04-嵌入式C工程实践.md)：ISR/线程边界、volatile、错误码、内存池、分层与状态机。
