# 目录说明

语音与实时通信：从 PSTN 到 IMS 的系统模型、语音编码与质量、RTP 媒体传输、SIP 信令、IMS/VoLTE、H.248 媒体网关与 VoIP 部署。

本目录是“语音”主题的正本：协议机制、媒体格式、运营商 IMS 与软交换都放这里。蜂窝空口上的语音承载与回落去 [03-蜂窝通信](../04-无线通信/03-蜂窝通信/.readme.md)，光猫语音口等产品配置去 [30-产品与方案/36-ONU-ONT](../../../30-产品与方案/36-ONU-ONT/.readme.md)。
