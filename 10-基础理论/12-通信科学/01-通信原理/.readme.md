# 目录说明

通信系统的通用原理：消息如何变成信号、多个用户如何共享资源、信道如何损伤信号、用什么指标衡量好坏。这里只写跨制式的“为什么”，具体制式去 02/03/04。

## 内容索引

- [00-通信系统与性能指标.md](./00-通信系统与性能指标.md)：通信系统模型、信源/信道编码、调制/解调，以及带宽/SNR/容量/误码率四个指标。
- [01-调制与编码.md](./01-调制与编码.md)：ASK/FSK/PSK/QAM、星座图、OFDM、线路编码与 FEC/LDPC/Polar 的取舍。
- [02-多址与双工.md](./02-多址与双工.md)：FDMA/TDMA/CDMA/OFDMA、FDD/TDD、调度接入与竞争接入。
- [03-信道与传输损伤.md](./03-信道与传输损伤.md)：衰减、噪声、失真、多径、干扰，dB/dBm 与链路预算。
