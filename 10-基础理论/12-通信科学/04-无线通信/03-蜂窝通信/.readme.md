# 目录说明

蜂窝通信基础：4G/5G 网络架构、空口物理层、层二与调度、选网与入网、QoS 承载与语音业务，以及 5G-A/6G 与毫米波的演进边界。

## 内容索引

- [00-蜂窝网络架构与演进.md](./00-蜂窝网络架构与演进.md)：2G→5G 演进、EPC/5GC 网元与功能划分、S1/X2/NG/Xn、Option 家族与 NSA/SA、CU/DU 与 IAB。
- [01-LTE与NR物理层.md](./01-LTE与NR物理层.md)：帧结构、RE/RB/PRB/REG/CCE、下行基带链、参考信号、物理信道、物理层过程与功控。
- [02-入网与移动性管理.md](./02-入网与移动性管理.md)：小区搜索、RRC 建立、NAS 注册、默认承载/PDU 会话、随机接入四步、切换与重选、TAU/RNAU 与寻呼。
- [03-层二协议与调度.md](./03-层二协议与调度.md)：MAC/RLC/PDCP/SDAP 分工、三层信道映射、调度器与 HARQ/ARQ、层二数据流与定时器。
- [04-小区选择重选与PLMN.md](./04-小区选择重选与PLMN.md)：PLMN 六类列表与选网时机、扫频与小区搜索、S 准则、小区重选优先级与门限。
- [05-QoS与承载.md](./05-QoS与承载.md)：EPS 承载与 QCI、PCC 策略链、5G PDU 会话/QoS 流/5QI、两级映射与 AMBR/GBR 执行点。
- [06-VoLTE与语音方案.md](./06-VoLTE与语音方案.md)：语音方案演化、IMS 在 VoLTE 中的位置、QCI 5/1 承载、CSFB/EPS Fallback/SRVCC；协议细节链接到 06-语音与实时通信。
- [07-5G-Advanced-6G与毫米波.md](./07-5G-Advanced-6G与毫米波.md)：5G-A（R18–R20）的版本边界与功能取舍、ITU IMT-2030 与 3GPP R21 的分工与时间表、毫米波链路预算与“覆盖换带宽”的取舍。

## 维护约定

- 一个主题一篇笔记：架构、物理层、入网、层二、选网、QoS、语音、演进各自独立，跨主题用链接。
- 新增笔记后，在本文件补充链接和一句话摘要，并同步 `../images/.readme.md` 与上级目录的篇数/图数。
- 素材多为课程 PPT 与二手整理，参数与流程以 3GPP 规范对应版本为准；无法核对的写“待验证”。
