# 目录说明

计算机组成、操作系统原理、编译与链接、网络编程基础。这里只放**通用原理与接口契约**，具体 Linux 实现、平台芯片差异和产品方案链接到 20/30/40。

## 内容索引

- [00-计算机组成与存储层次](./00-计算机组成与存储层次.md)：CPU/ISA 与微架构、五级流水线与冒险、Cache 层次与地址拆分、MESI、总线/DMA 与内存序。
- [01-操作系统抽象](./01-操作系统抽象.md)：进程/线程/协程、虚拟地址空间与 ASLR、fd/VFS 共享语义、系统调用与 vDSO、进程状态与一次 IO/COW。
- [02-编译与链接](./02-编译与链接.md)：预处理/编译/汇编/链接/装载、ELF section/segment、符号绑定与重定位、静态库抽取、动态链接与库搜索、交叉编译边界。
- [03-网络编程基础](./03-网络编程基础.md)：socket API、TCP/UDP 读写语义与定帧、四类 IO 模型、LT/ET、CLOSE_WAIT/TIME_WAIT、TCP 状态机与容量估算。

共 4 篇，20 张 SVG 图。图表索引见 [images/.readme.md](./images/.readme.md)。
