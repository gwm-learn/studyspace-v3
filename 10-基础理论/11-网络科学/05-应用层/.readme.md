# 目录说明

DHCP、DNS、HTTP、PPPoE、TR-069 等应用层协议及其在网关产品中的使用。

## 内容

- [00-应用层概览.md](./00-应用层概览.md)：应用层职责、进程/端口/域名、协议组织方式、协议地图与管理协议定位。
- [01-DHCPv4.md](./01-DHCPv4.md)：DORA 四步、报文与选项、租约 T1/T2、中继 giaddr/option 82、安全边界。
- [02-DHCPv6.md](./02-DHCPv6.md)：有状态/无状态、四步/两步、IA_NA/IA_PD、中继、DAD 与安全边界。
- [03-DNS.md](./03-DNS.md)：命名空间、报文与 RR、递归/迭代、缓存与 TTL、DoH/DoT 与 DNSSEC 边界。
- [04-HTTP.md](./04-HTTP.md)：报文、方法/状态码、连接复用、HTTP/1.1→2→3、缓存与安全边界。
- [05-SNMP.md](./05-SNMP.md)：NMS/Agent/MIB/OID、v1/v2c/v3、Get/Set/Trap 与安全边界。
- [06-UPnP.md](./06-UPnP.md)：SSDP 发现、设备描述、SOAP 控制、GENA 事件、IGD 端口映射与安全边界。
- [07-TR-069.md](./07-TR-069.md)：CWMP 会话、Inform/Connection Request、参数树、常用 RPC 与安全边界。
- [08-TR-369.md](./08-TR-369.md)：USP 角色、MTP、USP Record、消息类型、多控制器与 TR-069 对照。
- [09-OMA-DM.md](./09-OMA-DM.md)：DM Tree、SyncML 会话、常用命令、Bootstrap 与安全边界。
