# 目录说明

IPv4/IPv6、路由、NAT、ICMP、分片、组播等网络层知识。

## 内容

- [00-网络层概览.md](./00-网络层概览.md)：网络层职责、数据平面/控制平面、转发与路由、协议地图与边界。
- [01-IPv4.md](./01-IPv4.md)：IPv4 首部、地址与 CIDR、单播/组播/广播/任播、同网段与跨网段发送、转发流程。
- [02-IPv6.md](./02-IPv6.md)：128 位地址、固定首部与扩展头、SLAAC/DHCPv6、NDP、转发与过渡技术。
- [03-IP分片与MTU.md](./03-IP分片与MTU.md)：MTU 与帧长、IPv4/IPv6 分片字段、重组、PMTUD、MSS 钳制与隧道开销。
- [04-路由与路由协议.md](./04-路由与路由协议.md)：路由表与最长前缀、静态/动态路由、RIP/OSPF/IS-IS/BGP 定位与收敛。
- [05-NAT.md](./05-NAT.md)：SNAT/DNAT/MASQUERADE/PAT、conntrack 转换表、锥型 NAT、ALG 与穿透。
- [06-ICMP与ICMPv6.md](./06-ICMP与ICMPv6.md)：ICMP 报文与差错规则、ping/traceroute、NDP/MLD、PMTUD 反馈与安全边界。
- [07-组播IGMP-MLD.md](./07-组播IGMP-MLD.md)：组播地址与 MAC 映射、IGMP/MLD 成员管理、Snooping/Proxy、PIM 定位。
- [08-VRRP.md](./08-VRRP.md)：虚拟路由器、Master/Backup 选举、通告与切换、Track 联动、与 HSRP 对比。
- [09-WireGuard.md](./09-WireGuard.md)：Cryptokey Routing、Noise 握手、AllowedIPs、MTU、OpenWrt 配置语义。
