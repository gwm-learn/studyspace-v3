# 目录说明

Ethernet、VLAN、STP、LACP、ARP、交换转发等链路层协议与机制。隧道按承载对象归本层：PPPoE、L2TP、ZeroTier。

## 内容

- [00-链路层概览.md](./00-链路层概览.md)：链路层职责、成帧/寻址/介质访问、协议地图与边界。
- [01-以太网与MAC.md](./01-以太网与MAC.md)：Ethernet II 帧格式、MAC 地址、交换机自学习与转发、FCS 与 MTU。
- [02-VLAN与Trunk.md](./02-VLAN与Trunk.md)：802.1Q 标签、Access/Trunk/Hybrid 收发规则、PVID/native VLAN、VLAN 间通信。
- [03-STP-RSTP-MSTP.md](./03-STP-RSTP-MSTP.md)：根桥/根端口/指定端口选举、BPDU、端口状态与定时器、RSTP 快速收敛、MSTP 实例。
- [04-链路聚合LACP.md](./04-链路聚合LACP.md)：聚合逻辑、LACPDU 协商、活动成员选择、负载分担与成员一致性。
- [05-ARP.md](./05-ARP.md)：ARP 报文、同网段/跨网段解析、代理 ARP、免费 ARP、缓存老化与安全边界。
- [06-PPP与PPPoE.md](./06-PPP与PPPoE.md)：PPP 帧、LCP/PAP/CHAP/NCP 三阶段、PPPoE 发现/会话、Session ID 与 MTU 开销。
- [07-L2TP.md](./07-L2TP.md)：隧道/会话模型、LAC/LNS、控制消息与数据消息、UDP 1701、封装与 MTU。
- [08-ZeroTier.md](./08-ZeroTier.md)：L2 overlay、身份与 Network ID、VL1/VL2、P2P/中继、OpenWrt 配置语义。
