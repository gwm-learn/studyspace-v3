# 图型示例

每个文件演示一种图型，是"照着改"的样板，不是教程。由 [build_examples.py](./build_examples.py) 生成，不要手改 SVG。

| 示例 | 图型 | 什么时候用 |
|---|---|---|
| [01-stack.svg](./01-stack.svg) | 层叠 + 分组括号 | 分区表、协议栈、镜像层、A/B 槽 |
| [02-sequence.svg](./02-sequence.svg) | 时序 | 协议交互、握手、跨组件调用 |
| [03-graph.svg](./03-graph.svg) | 有向图 | 提交历史、依赖关系、变基前后 |
| [04-decision.svg](./04-decision.svg) | 决策分流 | 报错分类、排障路径、选型判断 |
| [05-timeline.svg](./05-timeline.svg) | 时间线 | 版本演化、标准代际、里程碑 |

重新生成：

```bash
python3 .图表模板/examples/build_examples.py
```

改图时复制对应函数、替换内容即可；坐标和间距由组件计算，不要从头手写。
