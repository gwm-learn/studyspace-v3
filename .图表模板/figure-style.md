# 图表模板规范

> 适用范围：本仓库所有技术示意图，包括协议流程、系统架构、数据路径、模块关系和排查路径。
> 模板实现：[svg-figure-template.py](./svg-figure-template.py)
> 示例输出：[example.svg](./example.svg)

目标：让同一仓库里的图在**版式、字体、配色、间距、组件语义**上保持一致，避免每张图各画一套。

## 1. 文件格式

- 源格式：SVG 1.1，纯文本，UTF-8。
- 画布宽度：由内容自动计算；默认最小 `800`，也可用 `width=` 指定。常用 `1200-1660`，但不强制。
- 画布高度：由内容自动计算；也可用 `height=` 指定。
- 根节点（`W`/`H` 为计算后的实际值）：

```xml
<svg xmlns="http://www.w3.org/2000/svg"
     width="W" height="H"
     viewBox="0 0 W H"
     font-family="'Noto Sans CJK SC','Source Han Sans SC','WenQuanYi Micro Hei',sans-serif">
```

- 背景：`<rect width="W" height="H" fill="#ffffff"/>`。
- 不嵌入外部图片、外部字体和 Base64。
- 文件命名：`图NN-主题.svg`，例如 `图14-包的一生总览-三层世界.svg`。
- 存放位置：笔记同目录的 `images/`。
- Markdown 引用：

```markdown
![图 NN · 主题](images/图NN-主题.svg)
```

## 2. 版式框架

以下是默认布局，不是强制版式；实际可按内容增减泳道/列、调整坐标和间距。

| 区域 | 位置 | 规范 |
|---|---|---|
| 左右外边距 | 36 | 内容区 `36 .. W-36` |
| 主标题 | `x=36, y=42` | 23px，`#0f172a`，700 |
| 副标题 | `y=70, 92` | 12.3px，`#64748b`，行距 22 |
| 分隔线 | `y=112` | `#e2e8f0`，1.2px |
| 图例 | `y=142` | 30px 线段 + 11px 标签 |
| 章节标题 | `y=176` 左右 | 12px，`#0f172a`，700 |
| 正文起点 | `y=190` 左右 | 泳道/节点/矩阵 |
| 底部说明 | 距底 36 | 12.3px，`#64748b` |

排版原则：

- 标题只写“图 NN · 主题：一句话结论”，不超过 2 行。
- 副标题 1-2 行，说明**怎么看图**，不写实现细节。
- 泳道/列数按内容决定（1-N）；三泳道只是常见示例，不是固定版式。
- 同一层级的节点宽度、间距、字号保持一致。
- 图高 = 最后一个元素底部 + 36，避免大片空白。

### 2.1 先选图型，再选组件

图的形状由**知识点**决定，不由模板决定。先在下表选图型，再找对应组件；**不要所有图都用"节点 + 箭头"硬凑**——硬凑的结果是读者看不出结构。

| 知识点类型 | 典型例子 | 图型 | 组件 |
|---|---|---|---|
| 分层 / 分区 / 栈 | 协议栈、Flash 分区、镜像层、A/B 槽 | 层叠图 | `stack()` + `bracket()` |
| 先后交互 | 协议握手、跨组件调用、漫游 | 时序图 | `sequence()` |
| 分叉 / 依赖 | 提交历史、依赖关系、变基前后 | 有向图 | `graph()` / `edge_boxes()` |
| 分类 / 排障 | 报错分流、选型判断、定位路径 | 决策图 | `decision()` |
| 演化 / 里程碑 | 版本发布、标准代际 | 时间线 | `timeline()` |
| 线性步骤 | 构建流程、启动顺序 | 流程行 | `flow_row()` |
| 多选对比 | 模式选择、方案取舍 | 矩阵 | `matrix()` |
| 拓扑 | 组网、部署、数据流经哪些设备 | 节点 + 箭头 | `node()` / `lane()` / `arrow()` |
| 状态迁移 | 连接状态机、升级回滚 | 状态图 | `chip()` + `edge_boxes()` |
| 纯数据对照 | 参数表、字段表、命令表 | **不要画图** | Markdown 表格 |

选型原则：

- 有"谁对谁说"→ 时序；有"谁依赖谁"→ 有向图；有"如果…就…"→ 决策。
- 一张图只回答一个问题；两个问题就两张图，不要叠在一起。
- **能用表格说清的，不要做成图**：图的价值在位置与箭头，不在排版。
- 图型选错比画得丑更伤理解——把时序压成流程行，读者会丢失"谁发起、谁响应"。

## 3. 色彩语义

| Token | 色值 | 语义 |
|---|---|---|
| `ink` | `#0f172a` | 主标题、节点标题 |
| `body` | `#334155` | 正文 |
| `dim` | `#64748b` | 副标题、说明文字 |
| `line` | `#e2e8f0` | 分隔线、表格线 |
| `bg` | `#f8fafc` | 中性节点背景 |
| `slate` | `#475569` | 中性组件、通用路径 |
| `muted` | `#94a3b8` | 次要箭头、弱化信息 |
| `green` / `green_bg` | `#0f9d58` / `#f2fcf5` | 到本机、允许、成功 |
| `indigo` / `indigo_bg` | `#4f46e5` / `#eef2ff` | 转发、路由、主路径 |
| `amber` / `amber_bg` | `#d97706` / `#fff9ee` | 本机发出、注意、待确认 |
| `red` / `red_bg` | `#dc2626` / `#fff5f5` | 丢弃、命中、风险 |
| `cyan` / `cyan_bg` | `#0891b2` / `#ecfeff` | 二层、桥、补充路径 |
| `grid` | `#cbd5e1` | 表格辅助线 |
| `white` | `#ffffff` | 画布、表格行 |

规则：

- 以下是默认语义色，不是强制规范；不同图可按实际语义覆盖。
- 同一张图内，同一语义保持一致；跨图可以复用默认色，也允许按内容调整。
- 颜色只做辅助，必须有文字标签、图例或 badge。
- 背景 tint 与描边同色系：绿/靛蓝/橙/红/青分别对应各自的 `*_bg`。
- 覆盖方式：`SvgFigure(palette={"green": "#..."})`，或给单个组件传十六进制颜色。

## 4. 组件规范

### 4.1 标题与副标题

- 主标题：23px，700，`ink`。
- 副标题：12.3px，`dim`，行距 22。
- 分隔线：1.2px，`line`，从 `x=36` 到 `x=1624`。

### 4.2 图例

- 线段长 30px，`stroke-width=3`。
- 标签 11px，600，`body`。
- 顺序建议：共用段 → A 给我 → B 过路 → C 我发。
- 图例放在标题下方、正文上方。

### 4.3 泳道标签

| 属性 | 值 |
|---|---|
| 尺寸 | 常用 `108 × 90`，按标题长度调整 |
| 圆角 | 9 |
| 填充 | 语义色 `*_bg` |
| 描边 | 语义色，1.2px |
| 标题 | 10.6px，700，`ink` |
| 副标题 | 9.4px，`dim` |
| 说明 | 9.0px，`dim`，行距 13 |

### 4.4 节点

标准节点：

| 属性 | 值 |
|---|---|
| 尺寸 | 常用 `220 × 76`，按内容调整 |
| 圆角 | 8 |
| 填充 | 语义色 `*_bg` |
| 描边 | 语义色，1.1px |
| 左侧色条 | 宽 4.5，圆角 2，填充同描边 |
| 标题 | 11.8px，700，`ink`，`x+13, y+19` |
| 正文 | 9.6px，`body`，`x+13, y+36`，行距 15.4 |
| badge | 10.2px，700，语义色，右对齐 `x+w-9, y+19` |

小节点（泳道内）：

- 常用尺寸 `158 × 82`，按内容调整。
- 标题 10.2px，正文 8.8px。
- 其余圆角、色条、行距不变。

### 4.5 箭头

- 线宽 2.4px，颜色 `slate`。
- 终点三角形约 9px。
- 次要/可选路径用 `stroke-dasharray="3 3"`，颜色 `muted`。
- 标签 10.2px，600，`dim`，放在线段中点附近。
- 箭头不要穿过节点文字。

### 4.6 说明框

| 属性 | 值 |
|---|---|
| 圆角 | 10 |
| 填充 | 语义色 `*_bg` |
| 描边 | 语义色，1.0px |
| 内边距 | 14-16 |
| 标题 | 10.6px，700，`ink` |
| 正文 | 10.2px，`body`，行距 18 |

用途：读图顺序、边界条件、常见误判、结论。

### 4.7 矩阵 / 表

| 属性 | 值 |
|---|---|
| 宽 | 按列数和内容分配，常用 600 |
| 表头高 | 30 |
| 行高 | 30 |
| 表头背景 | `#f1f5f9` |
| 分隔线 | `#e2e8f0`，0.8px |
| 表头文字 | 10.0px，700，`dim` |
| 单元格 | 10.0px，`body` |
| 首列 | 10.0px，700，`ink` |
| 允许 | `✓`，`green`，700 |
| 禁止/命中 | `✗`，`red`，700 |
| 代码 | 8.8px，monospace |

### 4.8 小标签（chip）

比节点轻一级，用于 DAG 节点、阶段标记、模式名。

| 属性 | 值 |
|---|---|
| 尺寸 | 高 28，宽按文字自动（最小 34） |
| 圆角 | 6 |
| 填充 | 语义色 `*_bg`，描边 1.2 |
| 文字 | 10.2px，700，居中 |
| 副文字 | 8.6px，`dim`，居中（`sub=`） |

宽高由 `chip()` 返回 `(x, y, w, h)`，可直接喂给 `edge_boxes()`。

### 4.9 连线与自动选边（edge_boxes / graph）

手写斜线一定会穿过中间节点。**有分叉时优先用 `edge_boxes()` 或 `graph()`**：它们按相对方位选出入口，必要时走直角。

| 参数 | 作用 | 默认 |
|---|---|---|
| `a` / `b` | 两个盒子 `(x, y, w, h)` | 必填 |
| `mode` | `auto` / `straight` / `elbow` | `auto` |
| `label` | 线中点标签 | 无 |
| `dashed` | 虚线（可选路径） | `False` |

选边规则：横向距离大于纵向时从左右边出，否则从上下边出；高度 ≤44 取垂直中心，>44 取 `y+h-12`（避开节点标题与正文）。

### 4.10 层叠与分组（stack / bracket）

`stack(x, y, w, rows)`：`rows` 为 `dict(label, tag?, color?)`，行高 38、间距 6，返回底部 y。

- 用于：协议栈、Flash 分区、镜像层、配置优先级。
- `tag` 右对齐，放"引导/只读/共用"这类角色说明。
- **说明框放在返回值之后**（`f.note(x, bottom + 30, ...)`），不要写死 y。

`bracket(x, y1, y2, label, color)`：竖向分组括号，把相邻几行归为一组（如 A 槽 / B 槽）。

### 4.11 决策分流（decision）

`decision(x, y, w, root, branches)`：一个根 + N 个分支，每支可带一句 `action`。

| 参数 | 说明 |
|---|---|
| `w` | 分支区总宽；每支等宽均分 |
| `root` | `dict(title, lines?, color?)` |
| `branches` | `dict(title, lines?, color?, action?)`，建议 ≤5 支 |
| 返回 | 最底部 y，便于接说明框 |

用法边界：分支要按**证据**分，不按"我觉得"分（如"非快进 / 权限 / 引用冲突"）；超过 5 支改用矩阵。

### 4.12 时序（sequence）

`sequence(x, y, lanes, messages)`：

| 参数 | 说明 |
|---|---|
| `lanes` | `[(名称, 颜色)]` 或 `[dict(name, color?)]` |
| `messages` | `dict(frm, to, label, color?, dashed?)`；`frm == to` 画自环 |
| `lane_gap` / `lane_w` | 列间距 / 表头宽，默认 230 / 190 |
| `step` | 相邻消息的行距，默认 38 |
| 返回 | 生命线底部 y |

规则：

- 竖线是生命线（虚线），不要画成实体方框。
- 消息标签放线上方，左对齐起点；返回消息用虚线。
- 只画"谁对谁说"；纯步骤用 `flow_row()`。

### 4.13 时间线（timeline）

`timeline(x, y, w, items)`：横轴 + 菱形节点，说明上下交错。

| 字段 | 说明 |
|---|---|
| `label` | 节点名（如 R1、v2.0） |
| `sub` | 一行补充（年份、能力） |
| `above` | 强制放上方；默认奇偶交错 |
| `color` | 节点颜色 |

用于版本演化、标准代际、里程碑；表达因果或分叉请用 `graph()`。

## 5. 实现方式

模板脚本只依赖 Python 标准库：

```bash
python3 .图表模板/svg-figure-template.py
```

默认生成同目录的 `example.svg`；也可以指定输出：

```bash
python3 .图表模板/svg-figure-template.py /tmp/my-figure.svg
```

核心 API：

| 方法 | 用途 |
|---|---|
| `header(title, subtitles)` | 画标题、副标题和分隔线 |
| `legend(items)` | 画图例 |
| `section_title(x, y, title)` | 画章节小标题 |
| `lane(x, y, ...)` | 画泳道标签 |
| `node(x, y, ...)` | 画节点 |
| `flow_row(x, y, nodes)` | 按顺序横排节点，自动画箭头；列数由内容决定 |
| `arrow(x1, y1, x2, y2, ...)` | 画箭头 |
| `note(x, y, w, title, lines)` | 画说明框 |
| `matrix(x, y, w, headers, rows)` | 画矩阵/表 |
| `chip(x, y, label, ...)` | 小标签块（DAG 节点、阶段标记） |
| `edge_boxes(a, b, ...)` | 两盒之间连线，自动选边、可走直角 |
| `graph(nodes, edges)` | 有向图 / DAG，节点用 chip |
| `bracket(x, y1, y2, label)` | 竖向分组括号 |
| `stack(x, y, w, rows)` | 层叠结构（分区、协议栈） |
| `decision(x, y, w, root, branches)` | 决策 / 分流图 |
| `sequence(x, y, lanes, messages)` | 时序图 |
| `timeline(x, y, w, items)` | 时间线 |
| `footer(lines)` | 画底部说明 |
| `save(path)` | 输出 SVG |

画布默认按内容自动计算宽高；也可以 `SvgFigure(width=..., height=...)` 固定。颜色可通过 `palette={...}` 或单个组件的十六进制颜色覆盖。

图型示例（**改图前先看这里**）：

```bash
python3 .图表模板/examples/build_examples.py
```

| 示例 | 图型 | 对应笔记里的真实用法 |
|---|---|---|
| [examples/01-stack.svg](./examples/01-stack.svg) | 层叠 + 分组 | 分区布局、协议栈、A/B 槽 |
| [examples/02-sequence.svg](./examples/02-sequence.svg) | 时序 | 协议交互、漫游、握手 |
| [examples/03-graph.svg](./examples/03-graph.svg) | 有向图 | 提交历史、依赖、变基前后 |
| [examples/04-decision.svg](./examples/04-decision.svg) | 决策分流 | 报错分类、排障路径 |
| [examples/05-timeline.svg](./examples/05-timeline.svg) | 时间线 | 版本演化、标准代际 |

每个示例只演示一种图型，复制对应函数改内容即可，不要从头写坐标。

`flow_row()` 的节点内容由实际主题决定，下面的标题只是占位示例：

```python
fig.flow_row(154, 190, [
    dict(title="步骤 A", lines=["说明 1"], small=True),
    dict(title="步骤 B", lines=["说明 2"], small=True),
    dict(title="步骤 C", lines=["说明 3"], small=True),
])
```


改图流程：

1. **先按 §2.1 选图型**，再打开 `examples/` 里对应的样板。
2. 复制样板函数（不要从头写坐标），替换标题、副标题、图例与内容。
3. 用对应的图型组件（`stack` / `sequence` / `graph` / `decision` / `timeline`）铺主体；线性步骤才用 `flow_row()`。
4. 最后加说明框、矩阵、底部注释；说明框接在组件返回值之后，别写死 y。
5. 默认不需要手动算高度；只有需要固定版式时才传 `width` / `height`。
6. 生成 SVG，检查 XML 与溢出。
7. 在 Markdown 中引用并检查链接。

## 6. 生成后检查

```bash
python3 - <<'PY'
import xml.etree.ElementTree as ET
ET.parse('example.svg')
print('svg ok')
PY
```

检查清单：

- [ ] **图型与知识点匹配**：分层用 `stack`、交互用 `sequence`、分流用 `decision`、依赖用 `graph`；没有拿流程行硬凑
- [ ] 一个图只回答一个问题；两个问题拆成两张
- [ ] 画布宽度由内容自动计算，没有溢出
- [ ] `viewBox` 与实际宽高一致
- [ ] 字体使用 Noto Sans CJK / Source Han Sans
- [ ] 颜色使用默认或自定义语义色，并有文字标签
- [ ] 标题、副标题、图例齐全
- [ ] 节点尺寸、字号、圆角、色条一致
- [ ] 箭头方向和标签清晰；没有穿过中间节点（必要时用 `edge_boxes`）
- [ ] 层叠图/时序图的说明框在返回值之后，没有压住最后一行
- [ ] 说明框/矩阵没有溢出
- [ ] 文件名为 `图NN-主题.svg`
- [ ] Markdown 图片链接有效
- [ ] SVG 可被 XML 解析

## 7. 维护约定

- 修改模板时，同时更新本规范、`svg-figure-template.py` 和示例。
- 不要手改 `example.svg` / `examples/*.svg`；改脚本后重新生成。
- 新增图型时：先补 §2.1 的选择表，再补组件、再补 `examples/` 样板，最后补 §4 的组件规范——顺序不能反。
- 新图优先复用现有组件，不新增近似重复的样式。
- 图片只表达结构和关系，详细解释放在 Markdown 正文。
