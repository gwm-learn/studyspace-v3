# 图片索引

本目录存放 Git 系列笔记的插图，由 `.图表模板/svg-figure-template.py` 生成。

- [图01-对象模型.svg](./图01-对象模型.svg)：工作区、索引、对象库与引用的写入关系。
- [图02-提交快照.svg](./图02-提交快照.svg)：每个 commit 指向一棵完整 tree，差异由两棵树比较得出。

- [图02-变基重放.svg](./图02-变基重放.svg)：rebase 把 B..feature 的提交逐个重放到新基底，生成 hash 不同的新提交。
- [图01-远程引用与数据流.svg](./图01-远程引用与数据流.svg)：本地 main、origin/main、远程 main 三者关系，以及 fetch/push 的数据流向。
