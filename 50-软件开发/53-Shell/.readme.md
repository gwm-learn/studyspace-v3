# 目录说明

## 内容

- [00-Shell执行模型与语法.md](./00-Shell执行模型与语法.md)：变量与引用、展开顺序、重定向、条件/循环/函数、退出码。
- [01-文本处理.md](./01-文本处理.md)：grep/sed/awk/find/xargs、正则方言、管线组合与边界。
- [02-脚本工程化与自动化案例.md](./02-脚本工程化与自动化案例.md)：严格模式、trap、锁、幂等，以及 SVN/权限/格式化的骨架。
