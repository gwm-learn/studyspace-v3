# 目录说明

Git hooks 目录，用于在本地提交前校验提交信息。

## 内容

- `commit-msg`：校验提交信息是否符合 `.gitmessage` 模板。
- 允许的格式：`<type>(<scope>): <subject>`。
- Git 自动生成的 `Merge`、`Revert`、`fixup!`、`squash!` 提交会放行。

## 启用方式

```bash
git config commit.template .gitmessage
git config core.hooksPath .githooks
chmod +x .githooks/commit-msg
```

## 维护约定

- 修改提交格式时，同时更新 `.gitmessage`、`commit-msg` 和根目录 `README.md`。
- 不要使用 `--no-verify` 绕过校验，除非确实需要。
