# 质量检查清单

## 0. 素材与来源门禁

动笔前先过这一关，后面 10 条才有意义。

- [ ] 素材形态已判定（仓库 / 网页 / 粘贴文本 / PDF / drawio），可信度已分级。
- [ ] 登录墙、JS 空壳页、需付费的链接：已向用户要正文，没有用记忆补全。
- [ ] 五类高危断言已核对：标准归属与版本、进程/包名、默认值与阈值、地址/端口/编号、"某实现必须 X"。
- [ ] 一手指规范/源码/官方文档；二手至少两处独立印证，否则标"待验证"。
- [ ] 二手素材里被推翻的说法，在正文里写清"常见说法 X，实际 Y"，没有静默修改。
- [ ] footer 有来源：仓库相对路径 / URL + 访问日期 / "用户提供"。
- [ ] 同一事实在全文只有一种说法。

## 1. 单篇 10 条硬指标

| # | 指标 | 不合格表现 |
|---|---|---|
| 1 | 开头一句话结论 + 可复述模型 | 直接贴目录/定义 |
| 2 | 为什么需要、不用会怎样 | 只写“XX 是某层协议” |
| 3 | 字段/结构表完整，含作用与坑 | 只有一张位图 |
| 4 | 正常流程 + 异常分支 | 只有成功路径 |
| 5 | 适用边界/反例 | 把实现说成标准 |
| 6 | 状态机/定时器（或明确“没有”） | 该有无，或无声省略 |
| 7 | 与相邻主题关系 | 只列链接不写边界 |
| 8 | 标准与关联链接 | 只有 RFC 编号 |
| 9 | 图在对应章节 + 读图说明 | 图堆在开头 |
| 10 | 名词解释三列 + 英文全称 | 只有中文/无缩写全称 |

通过线：**≥9/10，且 1/4/9/10 必须通过。**

## 2. 内容完备性

逐项打勾，缺项写明“本主题没有”：

- 定位与封装/归属
- 标识与地址
- 报文/结构/字段
- 交互/流程
- 状态机与定时器
- 异常与安全
- 实现/配置入口
- 观测/排障
- 标准与关联

## 3. 文风

- 8–15KB/篇；极小主题可 6KB，但指标不能少。
- 先结论后解释；短句；表格必须有“为什么/边界”列。
- 不写“抓包 / 常见坑 / 命令速查”章节。
- 不整段复制其他目录正文。

## 4. 目录级检查

- [ ] 目标目录 `.readme.md` 有链接 + 一句话摘要 + 图数。
- [ ] 上级 `.readme.md` 的篇数/链接同步。
- [ ] 新增目录有 `.readme.md`。
- [ ] `images/` 有 `.readme.md`。
- [ ] 协议/术语矩阵与正文一致（如果存在）。
- [ ] 相对链接可点；没有绝对路径、`file://`、Wiki 链接。
- [ ] 无敏感信息：密钥、Token、客户信息、现网日志、SDK 源码。
- [ ] 没有空文件/占位文件。
- [ ] 未自动 commit/push。

## 5. 自动化审计

```bash
python3 scripts/audit_kb.py 10-基础理论/11-网络科学
python3 scripts/audit_kb.py 20-平台与系统/21-Linux --figure-gaps
```

输出应满足：

- `dead_links = 0`
- `missing_images = 0`
- `forbidden_sections = 0`
- `missing_layer = 0`
- `glossary_missing = 0`
- `glossary_bad_rows = 0`

`--figure-gaps` 会列出“标题像流程/框架但章节内没有图”的 `##` 章节，人工判断是否补图。

## 6. 图的自检

- SVG 能被 XML 解析。
- 画布没有溢出：所有 `rect`/`text` 的右/下边界 ≤ width/height。
- 用 `sips -s format png` 渲染检查，不要用 `qlmanage` 判断宽图（会裁切）。
- 箭头不要穿过节点文字；图例不要压在节点上。
- 文件名、Markdown 引用、`images/.readme.md` 三处一致。
