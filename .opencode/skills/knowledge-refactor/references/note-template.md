# 主题名称

一句话结论：这个主题解决什么问题，最重要的模型是什么。

> 本篇定位：本篇覆盖什么、不覆盖什么；相邻主题去哪看。

## 1 · 一句话模型

用 1-3 句话给出可复述的模型，最好配一个 5 行以内的 text 图。

三个关键认知：

1. …
2. …
3. …

## 2 · 速览

| 项 | 内容 |
| --- | --- |
| 所属层/领域 | … |
| 核心对象 | … |
| 关键参数 | … |
| 典型场景 | … |
| 主要标准 | … |

## 3 · 报文/结构/字段

字段表必须有“作用”和“坑/边界”列；复杂结构配图或 text 布局。

## 4 · 交互/流程

正常流程 + 至少一个异常分支。图放在本节，配“读图”。

## 5 · 状态机与定时器

没有状态机就明确写“本主题没有连接状态机，只有 … 定时器”。

## 6 · 设计取舍与边界

- 为什么这样设计
- 代价是什么
- 什么时候不适用
- 常见误判（不叫“常见坑”）
