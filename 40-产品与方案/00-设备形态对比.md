# 设备形态对比

> 用途：区分交换机、路由器、CPE、智能网关、FTTR、ONU/ONT、光猫的边界，避免内容重复。

| 形态 | 核心定位 | 关键能力 | 关键协议/技术 | 软件栈 | 测试重点 |
|---|---|---|---|---|---|
| 交换机 | 二层/三层转发 | VLAN、STP、LACP、端口镜像 | Ethernet、VLAN、STP | 交换 SDK/OpenWrt | 吞吐、时延、环网、稳定性 |
| 路由器 | 路由与出口 | NAT、QoS、VPN、Wi-Fi | IP、NAT、PPPoE、Wi-Fi | OpenWrt/Linux | 转发性能、并发、稳定性 |
| CPE | 运营商客户侧终端 | 拨号、路由、远程管理 | PPPoE、DHCP、TR-069 | OpenWrt/厂商 SDK | 拨号、业务、入网认证 |
| 智能网关 | 家庭/企业智能中枢 | 插件、云管、智能家居 | Matter/Thread、Wi-Fi、TR-069 | OpenWrt/容器/插件 | 业务兼容、安全、云管 |
| FTTR | 光纤到房间组网 | 主从网关、光纤组网、漫游 | PON、OMCI、EasyMesh | 海思/厂商 SDK | 光功率、组网、漫游、运维 |
| ONU/ONT | PON 用户侧设备 | 注册、业务、语音/IPTV | PON、OMCI、VoIP | 厂商 SDK/OpenWrt | 注册、业务、互通、稳定性 |
| 光猫 | 家用 PON 终端（ONU/ONT 的俗称） | 光电转换、桥接/路由、Wi-Fi/语音 | PON、OMCI、TR-069、SIP | 厂商 SDK/OpenWrt | 注册、桥接/路由、三网业务、光功率 |

## 形态关系

```text
CPE（运营商用户侧设备）
  ├─ xDSL CPE
  ├─ PON CPE ── ONU/ONT ── 光猫（家用俗称）
  └─ 蜂窝 CPE

FTTR = 主光猫（PON + 路由）+ 从网关（房间覆盖）+ 光纤
智能网关 = 路由/光猫底座 + 插件 + 云管 + 智能家居协议
```

- **光猫与 ONU/ONT 是同一类设备**：规范名是 ONU/ONT，光猫是家用场景的俗称；产品形态见 [光猫产品形态](./46-ONU-ONT/03-光猫产品形态.md)。
- **ONU/ONT 与 CPE 是包含关系**：PON CPE 就是 ONU/ONT；CPE 还包括 xDSL 和蜂窝终端。
- **FTTR 不是一种「猫」**：它是一套「主网关 + 从网关 + 光纤」的组网方案，主网关通常由光猫/网关承担。

## 名词解释

> 缩写给出英文全称；非缩写用“—”表示。

| 术语 | 英文全称 | 解释 |
| --- | --- | --- |
| CPE | Customer Premises Equipment | 用户侧设备。 |
| ONU | Optical Network Unit | 光网络单元。 |
| ONT | Optical Network Terminal | 光网络终端。 |
| 光猫 | — | 家用 ONU/ONT 的俗称。 |
| FTTR | Fiber To The Room | 光纤到房间。 |
| PON | Passive Optical Network | 无源光网络。 |
| OMCI | ONT Management and Control Interface | ONT 管理控制接口。 |
| VLAN | Virtual Local Area Network | 虚拟局域网。 |
| STP | Spanning Tree Protocol | 生成树协议。 |
| LACP | Link Aggregation Control Protocol | 链路聚合控制协议。 |
| NAT | Network Address Translation | 网络地址转换。 |
| QoS | Quality of Service | 服务质量。 |
